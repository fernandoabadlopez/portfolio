# Home + case study template

Scope: home (`/en/`, `/es/`), mode Experience. Case study pages, mode Read. About and the pending galleries inherit the world.
Audience: recruiters scanning in seconds and simulation/graphics leads reading in depth, weighted equally.
Constraints: no new dependencies, routes/content/MDX prose untouched, nothing invented, reduced motion honoured.
Design read (taste): developer portfolio for recruiters and graphics leads, node-network interface language, native CSS + hand-written TS. Dials VARIANCE 7 / MOTION 6 / DENSITY 5.

## Direction contract

THESIS: The work is a live node network wired from CPU simulation to GPU pixels, merging into one output: NaN. It refuses the name-hero-plus-project-card-grid and the near-black neon dev portfolio.

OWN-WORLD: Cool grey network ground (#E3E6E9), lighter node bodies, ink #101214, grey bezier wires, dark viewer frames for anything rendered. One chartreuse accent (#C6F432) reserved for the active wire and selected node header. Martian Grotesk (wide, heavy display; regular body) and Martian Mono only for identifiers, parameters, figures and code. 4px radius everywhere, hairline rules, no shadows. States print inside nodes (pending media is said, never badged).

STORY: The visitor sees the name and role, sees the work laid out by where it runs (CPU or GPU), watches the same live cloth re-rendered through each project's technique, then opens a node or reaches the output node for contact.

FIRST VIEWPORT: Top-left the name set wide and heavy with the role line. Below, left seven columns: CPU and GPU node columns (case studies, slug as node name, title) wired into an output node NaN linking to About. Right five columns: dark viewer running a pullable XPBD cloth with a technique switch (xpbd, snow, bloom, ik error) plus the hovered node's parameters (tagline, stack). Primary action: open a node.

FORM: Network View, candidate 4 of 7 (Houdini/Nuke node networks). Seed key 4235a26c. Signature interaction: one live cloth, four techniques; hovering or focusing a node previews its technique in the viewer. Motion grammar: evaluation order on first load (nodes resolve, wires draw, output last), flow along the active wire, node-to-header morph on navigation. Raises: hover previews output before opening (algorave); states print in nodes (phosphor terminal); strict evaluation order with output last (Dong Ho); single accent for the active item (Push Pin); phones collapse to one vertical wire lane (multiplane).

ADAPTATION (finish review): the parameter pane moved from under the viewer to the left column, beside the output node, directly under the graph. At 1440x900 the viewer column could not hold frame, switch and pane inside the first viewport, and the left column had an empty block under the output node. Below 1180px the order is graph, viewer, parameters, NaN last, with per-box bus lanes instead of SVG wires, because there the output node follows the viewer and wires would cross it; the merge into one output is shown only at 1180px and up. The active wire is chartreuse over an ink casing for contrast on the grey ground. Switch labels name techniques (strain, ik error, bloom, snow) in network order.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
