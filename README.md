# portfolio

Personal technical portfolio for Fernando Abad López — real-time simulation and 3D graphics engineer.

See [PROJECT_BRIEF.md](PROJECT_BRIEF.md) for architecture and rules.

## Local development

```sh
pnpm install   # install dependencies
pnpm dev       # start the dev server
pnpm build     # production build
pnpm lint      # run ESLint
pnpm format    # run Prettier
```
